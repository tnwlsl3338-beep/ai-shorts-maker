01소재와 이용 권한

1GB 이하 · 최대 2시간 · 원본의 모든 화면 영역을 보존합니다.

02새로운 기획과 대본

입력한 사실·관점을 도입·전개·결론에 배치하는 템플릿 방식입니다. 생성형 AI나 자동 사실 검증은 사용하지 않습니다.

03필요한 장면과 직접 녹음한 해설

대본에 필요한 장면만 직접 선택하세요. 추가한 순서대로 배치하며 원본 소리는 제거합니다.

최대 5개 · 시작·종료는 초 단위 · 안전한 사용 비율이나 시간을 보장하지 않습니다.MP3·WAV·M4A 등, 100MB 이하, 6~180초. 내레이션 길이는 선택 장면 총 길이 + 도입·마무리 4초 이상이어야 합니다.

독자적인 도입·마무리 카드 + 선택 장면 + 새 내레이션 + ‘제작자 해설’ 자막으로 구성합니다. 내레이션이 길면 마무리 카드를 연장합니다. 기존 화면 자막은 삭제하지 않습니다.

CPU 처리에는 시간이 걸립니다. 말소리가 감지되지 않으면 자막을 지어내지 않고 중단합니다.

04–05완성본 검수와 다운로드

미리보기입니다. 아래 검수를 완료하면 파일 다운로드 버튼이 표시됩니다.

새로운 정보나 관점을 제공하는지 직접 확인해 주세요.

검수는 본인의 확인 기록이며 플랫폼 승인·법률 검토가 아닙니다. 중복 판정 회피나 수익화를 보장하지 않습니다.

재창작의 7가지 원칙

  • 소재의 이용 권한 확인
  • 원본과 다른 새로운 기획
  • 독자적인 해설 대본
  • 설명에 필요한 장면만 사용
  • 새로운 표현 요소 추가
  • 겉모습 변경에만 의존하지 않기
  • 게시 전 사람이 직접 검수
