# 다운로드용 영상

`shorts-video.mp4`는 사용자가 업로드한 원본의 11.2초 세로 변환본입니다. 720×1280 H.264/AAC MP4이며 새로운 해설이나 재창작 대본은 추가하지 않았습니다.

사용자가 이 파일의 GitHub 업로드에 동의하여 게시했습니다. 원본 영상, 개인 파일, 음성 모델은 포함하지 않습니다.

다운로드: GitHub에서 `shorts-video.mp4`를 연 뒤 **Download raw file**(아래쪽 화살표)을 누르세요. 브라우저에서 재생되면 영상 위에서 마우스 오른쪽 버튼 → **동영상을 다른 이름으로 저장**을 선택할 수 있습니다.
