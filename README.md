# 모먼트 · 한국어 쇼츠 재창작 스튜디오

원본을 다른 파일처럼 위장하지 않고, **새 기획 + 독자적인 해설 + 필요한 참고 장면**으로 제작하는 개인용 웹 앱입니다. 중복 판정 회피·수익화·권리 적법성을 보장하지 않습니다. 전체 지침은 `RECREATION_GUIDE.md`에 있습니다.

## 프로그램 다운로드와 실행

프로그램 상단의 **프로그램 ZIP**을 누르면 소스 코드와 실행 안내가 내려받아집니다. Python·FFmpeg·Whisper 모델·개인 영상은 ZIP에 포함하지 않습니다. 단독 실행 EXE가 아닙니다.

### 준비할 도구

- Python 3.12 권장
- FFmpeg와 ffprobe (libass·libx264 포함), PATH에 등록
- 한국어 폰트: Noto Sans CJK KR 권장
- 첫 실행 모델 다운로드용 인터넷, 모델 저장 여유 공간 약 1GB

Debian/Ubuntu: `sudo apt-get install ffmpeg fonts-noto-cjk`

### Windows

1. Python 3.12와 FFmpeg를 설치하고 PATH를 설정합니다.
2. ZIP을 압축 해제한 폴더에서 `start.bat`을 실행합니다.
3. 서버가 시작되면 브라우저 주소창에 `127.0.0.1:8000`을 입력합니다. 창을 닫으면 서버가 종료됩니다.

Windows 실행 스크립트는 제공하지만 실제 검증은 Linux/Python 3.12 환경에서 수행했습니다. 오류가 발생하면 아래 수동 실행 명령을 사용해 로그를 확인하세요.

### Linux / macOS

압축을 푼 폴더에서 `bash start.sh`를 실행하고 브라우저 주소창에 `127.0.0.1:8000`을 입력합니다. macOS에서도 Python·FFmpeg·한국어 폰트가 필요합니다. macOS 실행은 별도로 검증하지 않았습니다.

### 수동 실행 / 클라우드 환경

```bash
cd /workspace/ai-shorts-maker  # 다운로드한 경우 실제 압축 해제 폴더로 이동
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app:app --host 0.0.0.0 --port 8000
```

Windows 수동 실행은 `py -3 -m venv .venv` 후 `.venv\Scripts\python -m pip ...`, `.venv\Scripts\python -m uvicorn ...`을 사용합니다. `0.0.0.0`은 클라우드에서 접속이 필요할 때 사용하고, 개인 PC에서는 기본 스크립트처럼 `127.0.0.1`로 실행하세요.

## 제작 순서

1. **소재·권리 확인**: 원본 영상, 출처, 이용 권한 근거를 입력하고 권리 확인에 체크합니다. 업로드만으로 이용 권한이 확인되지는 않습니다.
2. **새 기획**: 주제, 독자적 관점, 근거가 있는 사실, 결론을 작성합니다. 새 가치를 제시할 수 없으면 제작을 보류합니다.
3. **새 대본**: ‘대본 구성 초안 만들기’를 누르고 내용을 직접 수정합니다. 초안은 입력 내용을 배치한 템플릿이며 생성형 AI나 사실 검증을 사용하지 않습니다. 대본 TXT·기획 JSON은 이 단계에서도 저장할 수 있습니다.
4. **장면 매칭**: 설명에 필요한 장면의 시작·종료(초)와 사용 이유를 입력합니다. 추가한 순서대로 구성합니다. 원본은 자동 분석·반복하지 않습니다. 안전한 사용 시간이나 비율을 가정하지 않습니다.
5. **내레이션**: 최종 대본을 직접 녹음해 MP3·WAV·M4A 등의 파일로 업로드합니다. TTS·음성 복제·브라우저 녹음은 포함하지 않습니다. 녹음 길이는 6~180초이며 ‘선택 장면 총 길이 + 도입·마무리 4초’ 이상이어야 합니다.
6. **합성**: 새 도입 카드 → 참고 장면 → 새 마무리 카드로 구성합니다. 원본 소리는 제거하고 직접 녹음한 해설만 넣습니다. 원본 화면 전체를 720×1280 안에 맞춰 워터마크·기존 글자를 보존합니다.
7. **검수**: ‘완성본 검수와 다운로드’에서 미리보기 후 권리·사실·음악·개인정보·새 가치 항목을 확인합니다. 새 내레이션을 Whisper로 인식하므로 실제 대본·발음과 자막이 맞는지 확인해야 합니다.

## 만든 파일은 어디서 다운로드하나요?

- **완성 영상·자막·제작 기록**: 화면 아래 ‘완성본 검수와 다운로드’에서 검수를 완료하면 **완성 영상 MP4**, **해설 자막 SRT**, **제작 묶음 ZIP** 버튼이 나타납니다.
- **제작 묶음 ZIP 내용**: 영상, 새 해설 자막, 대본, 장면 사용 이유·권리 근거가 담긴 기획 JSON, 검수 JSON, 전체 제작 지침.
- **프로그램·지침**: 화면 상단 또는 오른쪽 안내 패널의 다운로드 버튼.
- 다운로드한 파일은 보통 PC의 **다운로드 폴더**에 저장됩니다. 실제 위치는 브라우저 설정을 따릅니다.
- 서버의 원본·결과는 `data/<작업 ID>/`에 저장됩니다. 새 작업의 결과는 `recreation.mp4`, `recreation.srt`, `production.zip`입니다. 이전 자동 추출 작업은 `clip-0.mp4` 등의 이름을 사용합니다.
- 재창작 작업 상태와 검수 기록은 디스크에 저장되어 서버를 재시작해도 조회할 수 있습니다. 진행 도중 서버가 중단된 작업은 재업로드해야 합니다. 검수 전에도 미리보기는 가능합니다. 이것은 작업 순서 안내이며 복사 방지 장치는 아닙니다.

## 음성 인식과 제한

기본 모델은 `Systran/faster-whisper-small`이며 CPU/int8로 동작합니다. 첫 실행은 `huggingface.co`, `*.huggingface.co`, `*.hf.co` 연결이 필요하고 모델은 `data/models`에 캐시됩니다. `WHISPER_MODEL`에 모델명이나 로컬 모델 경로를 지정할 수 있습니다. TLS 검증을 끄지 마세요. 현재 준비된 클라우드 머신에는 small 모델 다운로드·로드를 완료했습니다.

- 원본은 1GB 이하·2시간 이하, 내레이션은 100MB 이하·180초 이하입니다.
- 화면 속 글자를 읽는 OCR이나 시각적 장면 이해는 포함하지 않습니다.
- 말소리가 없는 새 내레이션은 오류로 처리하며 대사를 지어내지 않습니다.
- 단순 반전·배속·필터로 판정을 피하는 기능, 워터마크 제거, 자동 게시 기능은 없습니다.
- 개인용 MVP입니다. 인증·사용자별 격리·자동 삭제가 없으므로 인터넷 공개 전에 접근 통제와 저장 용량 관리를 추가해야 합니다.
- 업로드 영상·녹음은 외부 AI API로 전송하지 않습니다. 종료한 작업 폴더는 직접 삭제해 용량을 관리하세요. 클라우드 게이트웨이의 별도 업로드 제한이 적용될 수도 있습니다.

## 검증

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
```

Linux에서 실제 FFmpeg 합성, 720×1280 출력, 원본 음성 없는 영상 지원, 내레이션 길이·장면 범위·권리 확인 검증, 검수 전 다운로드 차단, 검수 후 ZIP·MP4·SRT 다운로드, 작업 복구를 테스트합니다. 통합 테스트의 음성 인식은 고정 결과로 대체하므로 자막 인식 정확도나 실제 사실관계는 검증하지 않습니다. 첨부된 11.2초 원본은 실제 Whisper에서 말소리가 감지되지 않았으며, 그것만으로 새 해설의 자막 정확도를 보장할 수 없습니다.
